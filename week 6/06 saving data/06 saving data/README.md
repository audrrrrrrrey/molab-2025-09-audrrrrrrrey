# 06 recorder / music player

this app builds off of the music player with app storage i made last week, incorporating Pinlun's recorder and allowing the user to play both preset sounds and recorded sounds in one view. i used chatgpt for code help on combining the two audio players, since some of the syntax was unfamiliar to me. original music player was based off of jht's 03-ImageUiDemo-1-symbols, 03-UIGraphics-View, 04-Audio-State-Demo, and 05-AppStorageDemo demos, combining and modifying them into a single app.
