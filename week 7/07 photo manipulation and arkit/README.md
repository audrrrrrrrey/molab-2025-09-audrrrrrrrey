
## 07 ar drawing app
this week i started working towards my final project, which is an AR app that allows you to make spatial drawings. i started by trying to get a sense of how ARkit worked and getting a basic camera view set up. i then overlaid the camera with a drawing view, which is crude and definitely not spatial...but i plan to keep building this over the next few weeks, so it's alright for now. using the drawing view also gave me an intro to working with gestures, which i attempted to apply by having a long press save an image to your camera roll, but it didn't seem to work even after the plist permissions popup appeared, so that's another issue i'll be tackling next week.

so far, hacking with swift and youtube tutorials have been a huge resource! individual links are commented in the code.
